# sushen.dev

Personal website for Sushen, built as a lightweight static site and hosted on Vercel.

## Local development

No build step is required. Serve the repository root with any static file server:

```sh
python3 -m http.server 3000
```

Then open <http://localhost:3000>.

## Deployment

Import this GitHub repository into Vercel and keep the framework preset set to **Other**. The site deploys directly from the repository root.
